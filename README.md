## 🚀 Getting Started

### ✅ Prerequisites

Make sure you have a C/C++ compiler installed:

| Platform | Compiler |
|----------|----------|
| Linux / macOS | GCC / G++ |
| Windows | MinGW / MSVC |
| Any OS | Code::Blocks, Dev-C++, Visual Studio, CLion |

---

### 🔧 How to Compile & Run

**Using g++ (Linux/macOS terminal):**

```bash
g++ main.cpp -o assignment5
./assignment5
```

**On Windows (Command Prompt):**

```bash
g++ main.cpp -o assignment5.exe
assignment5.exe
```

**Using an IDE:**
1. Open the project folder in your preferred IDE
2. Import or open `main.cpp`
3. Click **Build** and then **Run**
